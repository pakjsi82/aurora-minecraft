# Aurora, Ontario in Minecraft blocks

A walkable 3D voxel model of downtown Aurora, Ontario, in the browser. Open `index.html`,
or visit the GitHub Pages link for this repository. No install or Minecraft needed.

- Built from OpenStreetMap data (building footprints, streets, parks) at 1 block = 1 metre.
- Building heights are estimated where OpenStreetMap has none, the ground is flat,
  and the trees are illustrative.
- Controls: mouse to look, WASD to move, F to fly, M for the map. On phones and tablets,
  use the on-screen joystick, drag to look, and the arrow buttons to jump or fly.
- The Town Square block (library, 1885 Church Street School, performance hall, footbridge,
  plaza and amphitheatre) is hand-built on the real footprints to match photos.
